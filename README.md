# AVISHKAR 2K26

Public event website for the AIT Innovation Hackathon. It contains event information, domain rules, coordinator contacts, the schedule and visitor information.

- [Register a team](https://portal.avishkarait.online/register)
- [Participant and administrator sign-in](https://portal.avishkarait.online/login)

The separate portal handles registration, payments, participant accounts and administration.

Run the public website locally with:

```sh
npm ci
npm run dev
```

Use `npm test` to check event rules and logistics and `npm run build` to create a production build.
